# 🚀 React პორტფოლიო | TBC IT Academy Homework

თანამედროვე, სწრაფი და სრულად ადაპტირებული (Responsive) პორტფოლიოს საიტი შექმნილი **React 19**-ისა და **Vite**-ის გამოყენებით.

პროექტი აგებულია **კომპონენტური არქიტექტურის** პრინციპების სრული დაცვით: მთავარი გვერდი დაყოფილია ლოგიკურ სექციებად, ხოლო ყველა განმეორებადი ვიზუალური ელემენტი რეალიზებულია მრავალჯერ გამოყენებადი (Reusable) კომპონენტების სახით.

---

## 📁 პროექტის სტრუქტურა და კომპონენტები

```text
src/
├── components/
│   ├── common/                  # 🔄 მრავალჯერ გამოყენებადი კომპონენტები (Reusable UI)
│   │   ├── Button.jsx           # უნივერსალური ღილაკი (primary, secondary, outline, ghost)
│   │   ├── Badge.jsx            # ტეგები და სტატუსის ინდიკატორები
│   │   ├── Card.jsx             # საბაზისო Glassmorphism ქარდი Hover და Glow ეფექტებით
│   │   ├── SectionTitle.jsx     # სექციის სათაური (Badge + Title + Subtitle)
│   │   ├── StatCard.jsx         # სტატისტიკის განმეორებადი ქარდი
│   │   ├── SkillCard.jsx        # უნარების კატეგორიის ქარდი პროგრეს-ბარებით
│   │   ├── ProjectCard.jsx      # პროექტის ქარდი (სურათი, ტეგები, ბმულები)
│   │   ├── ExperienceCard.jsx   # სამუშაო/განათლების ქრონოლოგიური ქარდი
│   │   ├── ServiceCard.jsx      # სერვისების/ძლიერი მხარეების ქარდი
│   │   ├── ContactCard.jsx      # საკონტაქტო არხის ქარდი (Email, Phone, Location)
│   │   └── DynamicIcon.jsx      # SVG & Lucide იკონების დინამიური რენდერი
│   │
│   ├── layout/                  # 📐 ჩონჩხის (Layout) კომპონენტები
│   │   ├── Navbar.jsx           # ფიქსირებული ნავიგაცია, თემის შეცვლა, მობილური მენიუ
│   │   └── Footer.jsx           # საიტის ქვედა ნაწილი, სოც. ქსელები, Top Scroll
│   │
│   └── sections/                # 📄 მთავარი გვერდის დამოუკიდებელი სექციები
│       ├── Hero.jsx             # მისალმება, მოკლე ბიო, CTA ღილაკები, პროფილი
│       ├── About.jsx            # ჩემ შესახებ, სტატისტიკა (StatCard) და სერვისები
│       ├── Skills.jsx           # ტექნოლოგიური სტეკი (SkillCard)
│       ├── Projects.jsx         # პროექტები კატეგორიების ფილტრაციით (ProjectCard)
│       ├── Experience.jsx       # კარიერა და განათლება (ExperienceCard)
│       └── Contact.jsx          # კონტაქტის ფორმა და არხები (ContactCard)
│
├── context/
│   ├── themeContextInstance.js  # Theme Context-ის ინიციალიზაცია
│   ├── ThemeContext.jsx         # Dark / Light რეჟიმის პროვაიდერი
│   └── useTheme.js              # Custom Hook თემის სამართავად
│
├── data/
│   └── portfolioData.js         # მონაცემთა გამოყოფილი წყარო (პროექტები, უნარები და ა.შ.)
│
├── styles/
│   ├── variables.css            # CSS ცვლადები (თემები, ფერები, რადიუსები)
│   ├── components.css           # Reusable კომპონენტების სტილები
│   ├── layout.css               # Navbar და Footer-ის სტილები
│   └── sections.css             # სექციების გრიდები და ლეიაუთები
│
├── App.jsx                      # აპლიკაციის მთავარი კომპონენტი
├── index.css                    # გლობალური სტილები და რისეთი
└── main.jsx                     # აპლიკაციის საწყისი წერტილი
```

## ✨ ძირითადი ფუნქციონალი

1. **მთავარი გვერდის დაყოფა სექციებად:**
   - `Hero`: მისალმება, დეველოპერის პოზიცია, სტატუსი, CTA და სოციალური ბმულები.
   - `About`: დეტალური ისტორია, სტატისტიკური მაჩვენებლები და სერვისები.
   - `Skills`: ტექნოლოგიური სტეკი 3 მიმართულებით (Front-End, ხელსაწყოები, პრინციპები).
   - `Projects`: პროექტების კატალოგი ინტერაქტიული კატეგორიების ფილტრით (All, React, Fullstack, UI).
   - `Experience`: ქრონოლოგიური timeline სამუშაო და სასწავლო გამოცდილებით.
   - `Contact`: საკონტაქტო ბარათები და ინტერაქტიული საკონტაქტო ფორმა წარმატების შეტყობინებით.

2. **მრავალჯერ გამოყენებადი (Reusable) კომპონენტები:**
   - `ProjectCard`: გამოიყენება თითოეული პროექტის ჩვენებისთვის (Props-ზე დაფუძნებული).
   - `SkillCard`: გამოიყენება უნარების თითოეული კატეგორიისთვის.
   - `StatCard`: გამოიყენება რიცხვითი სტატისტიკისთვის.
   - `ExperienceCard`: გამოიყენება სამუშაო/განათლების ისტორიისთვის.
   - `SectionTitle`: ერთიანი სტილის სათაური ყველა სექციაში.
   - `Badge`, `Button`, `Card`, `ContactCard`, `ServiceCard`.

3. **Dark / Light თემის გადამრთველი:**
   - ჩაშენებული `ThemeProvider` და `useTheme` ჰუკი.
   - არჩეული თემის დამახსოვრება მომხმარებლის ბრაუზერში (`localStorage`).

4. **მობილური ადაპტაცია (Responsive):**
   - მობილური Hamburger მენიუ გვერდითი/ჩამოსაშლელი ნავიგაციით.
   - მოქნილი CSS Grid & Flexbox სისტემა.

## 🛠️ გაშვების ინსტრუქცია

1. დამოკიდებულებების ინსტალაცია:
```bash
npm install
```

2. დეველოპმენტ სერვერის გაშვება:
```bash
npm run dev
```
გახსენით ბრაუზერში: `http://localhost:5173/`

3. საპროდაქშენო ბილდის აწყობა:
```bash
npm run build
```

4. ლინტერი / კოდის შემოწმება:
```bash
npm run lint
```
